# 도토리섬

실제 시간으로 흘러가는 작은 섬에서 과일 따기, 조개 줍기, 낚시, 곤충 채집, 이웃과 대화를 즐기는 아늑한 생활 게임 프로토타입입니다. 설치 없이 `index.html`을 브라우저로 열면 바로 플레이할 수 있어요.

## 조작법
| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 (Shift 달리기) |
| Space / E | 줍기, 나무 흔들기, 낚시, 대화 |
| I | 가방 |
| C | 도감 |

휴대폰에서는 화면의 조이스틱과 A 버튼을 사용합니다.
